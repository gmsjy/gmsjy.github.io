# 主题画廊：四套参考主题设计（v1.0 · 2026-09-04）

默认主题「墨理」之外，Typall 官方提供四套**风格迥异的外置参考主题**，随仓库放在 `typall/themes/` 下。它们承担双重职责：

1. **开箱可用的成品主题**——`[theme] name = "..."` 一行启用；
2. **主题作者的进阶示范**——分别展示暗色适配、衬线正文、partials 结构接管（留白）、圆角软阴影等不同定制路线，全部遵守 `THEME-SPEC.md` 的 class / 占位符 / 令牌契约。

四套主题均为**纯外置主题包**（零 Rust 代码改动）：只含 `style.css`（留白额外含 `partials/post_list.html`），骨架模板复用内置「墨理」，缺失项按 §1 规则逐项回退。也可用 `typall theme package --name <name>` 打包分发。

> 注：`typall/themes/` 下另有 `comments-demo/`——giscus 评论区的示范主题（style.css + template.html，含完整配置注释），见 typall/README.md「评论系统」一节；它是功能 demo，不属于本画廊的参考主题。

## 总览

| 目录 | 中文名 | 风格一句话 | 适用场景 | 明暗策略 |
|------|--------|-----------|----------|----------|
| `themes/obsidian/` | 曜石 | 暗色工作台，代码是主角 | 技术 / 开发博客 | **纯暗色**（不随系统切换） |
| `themes/paper/` | 纸砚 | 印刷纸面，砚台纸墨 | 数理 / 学术长文 | 纯亮色（附打印样式） |
| `themes/minimal/` | 留白 | 减法到黑白，零圆角 | 作品集 / 随笔 | 纯亮色 |
| `themes/citrus/` | 柑橘 | 暖色手作，米纸橘果楷体 | 个人随笔 / 生活博客 | 纯亮色 |

> 「明暗策略」是各主题的**设计决策**而非缺陷：曜石定位即暗色品牌；纸砚以印刷为喻，暗色会破坏纸感隐喻；留白、柑橘同理。需要明暗自适应请用墨理，或以墨理的 `@media (prefers-color-scheme: dark)` 块为模板自行扩展（THEME-SPEC §8.2）。

## 一、曜石（obsidian）—— 暗色极客

### 设计理念

面向技术/开发博客的「深夜工作台」审美。三条取向：

- **代码是主角**：代码块底色比页面底更深（内嵌感），重做 `--tok-*` 语法高亮配色保证暗底可读；正文标题用**等宽字体**，呼应终端气质。
- **霓虹点睛**：唯一强调色「霓虹青」，只在链接 / hover / 选中态出现；hover 附带同色低透明度光晕，克制但清晰。
- **纯暗色**：不设亮色变体——暗色是这套主题的身份，不是亮色主题的附属品。

### 设计令牌（单一暗色）

| 令牌 | 取值 | 说明 |
|------|------|------|
| `--bg` | `#0d1017` | 蓝黑底 |
| `--surface` | `#131722` | 卡片 / TOC / 专栏导航 |
| `--surface-2` | `#1a2030` | 次级底：tag / 行内 code |
| `--fg` / `--fg-strong` | `#d3d8e3` / `#f3f5fa` | 正文 / 强调 |
| `--muted` / `--faint` | `#8a93a8` / `#5d6678` | 次级 / 提示 |
| `--accent` / `--accent-strong` | `#39c5cf` / `#7adfe6` | 霓虹青 / hover 提亮（暗色下 hover 向亮，与墨理相反） |
| `--accent-soft` | `#12333a` | 青色暗底 |
| `--quote` / `--quote-soft` | `#b4a4f4` / `#232038` | 引用柔紫 |
| `--border` / `--border-strong` | `#1f2635` / `#2c3547` | 边框 / 分隔线 |
| `--code-bg` / `--code-ink` | `#0a0d14` / `#c8d3e0` | 比页面底更深的「内嵌」代码块 |
| `--maxw` | `54rem` | 略宽，照顾代码行 |
| 标题字体 | `var(--mono)` | 等宽标题（h1–h4、站点名、列表标题） |
| `--tok-*` | 见 style.css | 语法高亮重配（集合取自构建产物实际值） |

### 落地范围

`style.css` 全量组件覆盖；`::selection` 与滚动条配色；无 partials / 模板。

### 验收标准

1. 暗底下代码块语法高亮全部可读（无深蓝吃深底）；
2. MathML / SVG 两种公式渲染正常，公式编号可见；
3. 首页 / 文章 / 标签 / 归档 / 搜索页目检无亮色残留（白底闪块）。

## 二、纸砚（paper）—— 学术纸感

### 设计理念

面向数理/学术内容的「印刷纸面」。与墨理同属亮色衬线系，但更冷静克制：

- **正文全衬线**：与墨理「衬线标题 + 无衬线正文」相反，纸砚正文走 `STIX Two Text → 宋体` 学术衬线栈，行高 1.92——对应「论文正文是衬线」的印刷惯例（屏显长文慎用，故墨理不做）。
- **三线表（booktabs）**：去掉全部竖线与斑马纹，只留顶线、表头线、底线——学术表格的标准形态。
- **单一深红点睛**：绛红「朱砂」只出现在链接与集合页标题点缀；其余近全灰阶。引用块用藏蓝左边线区分。
- **打印友好**：附 `@media print` 收起顶栏/页脚/导航，正文即论文。

### 设计令牌（亮色）

| 令牌 | 取值 | 说明 |
|------|------|------|
| `--bg` / `--surface` | `#ffffff` / `#ffffff` | 纯白纸面 |
| `--surface-2` | `#f7f6f3` | 行内 code / th 底 |
| `--fg` / `--fg-strong` | `#1c1c1c` / `#000000` | 近黑正文 / 纯黑强调 |
| `--muted` / `--faint` | `#565656` / `#8f8f8f` | |
| `--accent` / `--accent-strong` | `#8c1f28` / `#6d141c` | 朱砂 / hover 深化 |
| `--accent-soft` | `#f6ebeb` | 朱砂浅底 |
| `--quote` / `--quote-soft` | `#34506b` / `#eef2f6` | 藏蓝引用 |
| `--border` / `--border-strong` | `#e3e1dc` / `#c9c6bf` | |
| `--code-bg` / `--code-ink` | `#f7f6f3` / `#3a3a3a` | |
| `--maxw` | `50rem` | |
| 正文与标题字体 | `var(--serif)` | `STIX Two Text, Georgia, "Times New Roman" → 宋体系` |

### 落地范围

`style.css` 全量组件覆盖；表格 booktabs 化、图片去圆角细边框、`@media print`；无 partials / 模板。

### 验收标准

1. 物理/数学示例文章：公式编号、三线表、cetz 插图渲染符合学术排版预期；
2. 正文标题锚点链接（`article a`）朱砂色、正文全衬线不违和；
3. 浏览器打印预览无顶栏/页脚噪音。

## 三、留白（minimal）—— 极简黑白

### 设计理念

把装饰减到黑白的「画廊白墙」。它是四套中唯一的**结构层定制示范**：

- **单色系**：强调色即墨色本身——hover 不变色，靠下划线与透明度给反馈；零圆角、零阴影、细边框。
- **网格列表**：用 `partials/post_list.html` **整块接管**列表渲染（`{% for p in posts %}`），把首页/标签页/归档的列表改为双栏卡片网格——这是「不改 Rust 就能改结构」的官方示范。
- **呼吸感**：内容宽度收窄到 46rem，标题字距收紧、留白放大。

### 设计令牌（亮色）

| 令牌 | 取值 | 说明 |
|------|------|------|
| `--bg` / `--surface` | `#ffffff` / `#ffffff` | |
| `--surface-2` | `#f4f4f4` | |
| `--fg` / `--fg-strong` | `#1a1a1a` / `#000000` | |
| `--muted` / `--faint` | `#666666` / `#999999` | |
| `--accent` / `--accent-strong` | `#1a1a1a` / `#000000` | **强调色 = 墨色**（单色设计的关键决策） |
| `--accent-soft` | `#f0f0f0` | |
| `--quote` / `--quote-soft` | `#1a1a1a` / `#f7f7f7` | |
| `--border` / `--border-strong` | `#e6e6e6` / `#cccccc` | |
| `--code-bg` / `--code-ink` | `#f4f4f4` / `#1a1a1a` | |
| `--maxw` | `46rem` | |
| 全局圆角 | `0` | 零圆角是身份，不是遗漏 |
| 字体 | 全无衬线 | 标题 500–600 字重、字距 `-0.01em` |

### 落地范围

`style.css` 全量组件覆盖 + `partials/post_list.html`（网格接管，`{% if %}` 守卫可选字段，tags 逗号字符串 `split` 后逐枚举）。无模板。

### 验收标准

1. 首页 / 标签页 / 归档列表呈现双栏卡片网格；窄屏回落单栏；
2. 搜索页结果（内联 JS 复用 `.post-list` 结构）在网格布局下不破版；
3. 交互反馈全部来自下划线/明度变化，无彩色残留。

## 四、柑橘（citrus）—— 暖色文艺

### 设计理念

与墨理互补的「暖纸手作」：米色纸面 + 橘果强调 + 楷体标题，个人随笔气质：

- **楷体展示层**：标题走 `霞鹜文楷 → 楷体` 栈（正文仍无衬线保证屏显可读）——中文屏幕上少见的「手写感」标题，字体缺失时回退宋体系不塌。
- **大圆角软阴影**：卡片 14px 圆角、图片圆角 + 低透明度暖褐阴影、胶囊全圆——与留白完全相反的路线。
- **暖色闭环**：底色米、正文暖褐墨、引用橄榄绿浅底卡片化（不做硬左线）。

2. 卡片/图片/代码块圆角与阴影统一（14px 系）；
3. 公式编号、TOC、分页等全部组件在暖色令牌下无冷色残留。

## 已知限制

1. **「复制到公众号」预览色不跟随**：`serve.rs` 的公众号 CSS-inliner 硬编码了墨理亮色色值，四套主题下复制的剪贴板样式仍是墨理配色。属已知耦合，后续可参数化为读取当前主题令牌。
2. **骨架模板复用墨理**：四套均不提供 `template.html`，顶栏/页脚结构（含「跳到正文」无障碍链接、搜索入口）与内置一致。结构性定制示范见留白的 `partials/post_list.html`。
3. **搜索固定 id**：`#search-input` / `#search-results` 由内置模板保证，四套主题不触碰。

## 实现记录（2026-09-05 实测踩坑）

四套主题已全部实现并通过示例站目检（构建 + serve + 浏览器截图，见 `_shots/`）。踩坑记录：

1. **`--tok-*` 实际取值集合**：typst 0.15 默认高亮主题共 9 个 token 色
   （`16718d 198810 1d6c76 301414 4b69c6 74747c 8b41b1 b60157 d73948`），
   其中 `#301414`（近黑默认字色）与 `#16718d`（深蓝）在暗底不可读——曜石已全部重映射（见其 style.css 文末）。
   提取方法：写一篇覆盖常见语言的探针文章构建后 grep 产物。
2. **暗色主题 × typst SVG 的硬编码填充**：typst 导出的公式/插图 SVG 内嵌
   `fill="#000000"`（552 处/篇）与 `stroke="#000000"`，暗色页面下公式不可见——**内置墨理的夜墨模式同样受影响**。
   曜石在主题层用属性选择器整体重映射（`article svg [fill="#000000"] { fill: var(--fg) }`，
   展示属性优先级最低，任意 CSS 可覆盖；复制到公众号路径走 DOM 克隆不受影响）。
   长期方案应在引擎层让 SVG 使用 `currentColor`。
3. **tera `split` 的参数名是 `pat` 不是 `sep`**：`{% for t in p.tags | split(pat=", ") %}`。
   THEME-SPEC §2.4/§4/§5 原文档误写为 `sep`（`join` 才用 `sep`），已随本次修正；
   首个版本的留白 partial 即踩此坑（构建期报 `Filter 'split' expected an arg called 'pat'`）。
4. **网格列表与搜索页兼容**：搜索页内联 JS 往 `.post-list` 里塞结果项，留白的网格容器天然兼容
   （单结果时即单卡片）；归档页每月一组 `.post-list`，同布局成立。
5. **楷体回退链**：Windows（KaiTi/楷体）与 macOS（Kaiti SC/STKaiti）直接生效；
   装有霞鹜文楷（LXGW WenKai）时优先使用。全部缺失时回退宋体系，不破版。
6. **serve 配置快照缺陷（已修复）**：watch_loop 曾持有**启动时的 config 快照**
   （`Config` 被 move 进监听线程，typall.toml 变更后不重读），热重建沿用旧配置——
   运行中切换 `[theme] name` 不生效，编辑主题 CSS/模板则正常。
   现已改为每次重建前 `reload_config` 重读（解析失败沿用旧配置并告警），
   附回归测试 `serve::tests::reload_config_*`，端到端实测热切换主题即时生效。
   另：Windows 中文无真正等宽字体，曜石的等宽标题中文回退为宋体系，属平台字体生态限制。
