痛点引子 「公式抄到 Word 里全乱了」

你一定经历过：数学笔记写到一半要抄一个分式，Word 里的公式编辑器弹出来又卡又难用，最后只能手写拍照。到了高三总复习，翻起三年的笔记，格式五花八门、图找不到、公式看不清。而隔壁那个用 Typst 记笔记的同学，打开一个 PDF——公式像教科书一样整齐，每张图都干净利落，一键还能重新编译。

工具不产生知识，但工具决定知识的保存质量与复用效率。这一篇介绍本系列全部配图的生产方式——Typst 与 CeTZ——以及它们如何反过来成为你的学习工具。

知识地图 三件工具的分工

图 17-1　数理学习工具箱：Typst、CeTZ、仿真的分工

三件工具各司其职：Typst 是排版系统，负责把公式和文字组织成可长期维护的文档；CeTZ 是 Typst 的绘图库，本系列所有配图都由它绘制——坐标轴、受力图、知识树，全部是几行代码；仿真与表格工具（Python、电子表格）负责数值实验与数据处理。三者共用一套文本格式，笔记、图、数据可以放在同一个工程里。

核心讲解 两个核心：工程结构与绘图流程

核心概念一：内容与样式分离。

图 17-2　一个最小的 Typst 笔记工程结构

Typst 工程的黄金结构是三件套：模板文件定样式、figures 目录放图、正文目录写笔记。正文通过 #import 引用模板与图片。这种「内容与样式分离」的思路初中生也能上手：你只管往 notes 里写，长相由模板统一保证。三年后回看，所有笔记风格一致、公式全部可检索——这是纸笔笔记做不到的。

核心概念二：画图的迭代流程。

图 17-3　CeTZ 画图四步：草图 → 坐标 → 编译 → 微调

用 CeTZ 画图的流程和做物理题惊人地像：先画草图（建模），再写坐标（列方程），然后编译预览（求解），最后微调（检验）。它还有一个做手绘做不到的能力：改一个参数，整张图重画——「把抛物线开口变小一点」只需要改一个数字。

更深一层：为了画对一张函数图，你必须真正理解它的定义域、单调性和关键点。画图是理解的自检器——画不出来，就说明还没懂。本系列每篇文章的配图都是这个方法的产品，你也可以立刻复制。

例题拆解 半小时上手第一张 CeTZ 图

✎ 上手示范：画一条抛物线

第一步，安装 Typst（官网或包管理器，免费）。第二步，新建 first.typ，输入：

#import "@preview/cetz:0.5.2"
#cetz.canvas(length: 1cm, {
  import cetz.draw: *
  axes(-2.6, 2.6, -0.6, 4.6, x-step: 1, y-step: 1)
  curve(x => x * x, -2.1, 2.1)
})

第三步，typst compile first.typ，一张带坐标轴的标准抛物线图出炉。第四步，把 x * x 改成 x * x * x，重新编译——三次函数出现了。

二十分钟内，你完成了从安装到自定义函数图像的全流程。这个正反馈 loop 是工具学习的全部动力：每次只多学一个组件（本系列 styles.typ 里的九大组件就是现成的弹药库），一个月后你就能画出老师课件级别的插图。

工具学习还有一个「性价比金字塔」值得了解：底层是纯文本与版本思维（一切皆 .txt，改动可回溯——Typst、Python 全部兼容）；中层是模板复用（一次搭建、终身受益的笔记与报告骨架）；顶层才是自动化（脚本批量处理、代码生成图表）。多数人的误区是直奔顶层学编程，结果被语法劝退。正确的路径是从底层开始：先把笔记全部转成纯文本，再套模板，最后顺手学一点自动化——需求驱动的工具学习，效率是不解自明的。

思维方法 工具思维：让机器干机器的活

⭐ 自动化的三个层次

第一层：手懒——重复劳动交给工具（排版、画格点、算数值）。第二层：眼高——用统一的模板逼自己把知识结构化（模板的栏目就是知识组织的检查单）。第三层：可复用——今年的错题模板明年还能用，画过的坐标系改改参数就是新的。

工具的终极价值不是炫技，而是把省下来的时间全部还给思考。

行动清单 今天就能做

仿真工具还有一个高中门槛内的应用场景：验证作业答案。一道斜面滑块题算出末速 6 m/s，用二十行 Python 代码以 0.001 秒步长模拟全程，输出 6.02 m/s——两种独立路径得出一致结果，可信度倍增。这种「用计算验证手算」的习惯有三重收益：检查了手算错误、学会了仿真、建立了「同一问题多路径交叉验证」的科研直觉。工具的终极用途不是替代思考，而是给思考配一个不知疲倦的复核员。

快问快答：三个高频疑问

  • 零基础学 Typst 要多久？ 答：跟着模板写笔记，第一天就能上手；两周可脱离模板自由排版。
  • 手写笔记和电子笔记哪个好？ 答：思考过程手写更利于记忆，存档复用电子更优——草稿手写、成稿电子是黄金组合。
  • 代码画图比手画慢怎么办？ 答：初期慢是学费。建立自己的组件库后，改参数重画的速度远超手绘。
