原子核物理：放射性、结合能与核能

上一课看到光有波动性；这一课钻进原子最深处——原子核。放射性、核反应、质能方程，把物理学从「能量守恒」推向更根本的「质能守恒」，也把人类带到了核能（与核武器）的门口。

天然放射现象：原子核自己会变

贝克勒尔发现铀盐能使底片感光——原子序数大于 83 的元素（以及不少人工核素）会自发放出射线，这种现象叫天然放射现象。放射性只与原子核有关，与核外电子、化学状态、温度压强无关——它是核性质的直接展示。

三种射线一览：

| 射线 | 本质 | 电荷 | 穿透力 | 电离能力 | |——|——|——|——–|———-| | | 氦核 | | 一张纸可挡 | 最强 | | | 高速电子流 | | 穿几毫米铝板 | 较弱 | | | 高频电磁波（光子） | 0 | 穿几厘米铅板 | 最弱 |

左手定则判定偏转方向：磁场指向纸外、速度向右 → 正电的 向上弯，负电的 向下弯，中性 不偏。三射线在磁场中的行为是区分它们最经典的实验手段。

质量亏损与质能方程

实验发现：原子核的质量小于组成它的核子质量之和，差值叫质量亏损 。爱因斯坦给出解释：

公式 (6)

核子结合成核时「亏损」的质量以能量形式释放——这部分能量叫结合能， 越大核越稳定。任何核反应只要释放能量，就伴随质量亏损；反之要把核拆开，必须补回这么多能量。

记忆点：质量亏损不是「质量消失了」，而是质量与能量本是一体（质能守恒取代了孤立的质能各自守恒）。 是常用换算。

裂变与聚变：两种获能路径

  • 重核裂变： 俘获一个慢中子后分裂成两个中等核并放出 个中子——中子再引发新的裂变，形成链式反应（核电站的反应堆用控制棒控制链式反应速率）；
  • 轻核聚变：氘、氚聚合成氦，单位质量释能远大于裂变——太阳的能量来源；实现需要上亿度高温克服核间库仑斥力（「人造太阳」托卡马克研究的正是可控聚变）。

例：某放射性核素半衰期 天，原有 ，经过 天后剩多少？衰变掉了多少？

个半衰期：剩余 ；衰变掉 。

易错：题问「衰变掉多少」时答「剩 2 g」就掉坑了。

解题方法论

  • 核反应方程两查：写完立刻查「上标和下标」各守恒；未知核/粒子用守恒两条解出；
  • 射线三件套：穿透力、电离能力、磁场偏转——按 顺序对号入座；
  • 半衰期先数次数：，再套 ；注意区分「剩余」与「衰变掉」；
  • 质能方程单位：质量用 “kg” 配 ，或用原子质量单位 配 ——两套单位不要混。

一句话收束：核物理把「元素不可变」的信念打碎，又用 把质量与能量焊在一起——微观世界的规则，恰恰在这里决定了人类世界的能源格局。
