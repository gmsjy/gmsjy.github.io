稳态与调节：神经、体液、免疫三张网

你的体温、血糖、pH，全天波动不到几个百分点——身体里亿万个细胞「泡」在一个被精密恒温恒浴的海洋里。维持这片内海稳定的是三张协作的网：神经系统「有线宽带」，激素「邮政快递」，免疫系统「安防部门」。

内环境与稳态

体液 细胞内液（约 ） 细胞外液（约 ）。细胞外液即内环境，由三部分构成：

  • 血浆（血细胞的居所）↔ 组织液（组织细胞的居所）：双向渗透，隔毛细血管壁；
  • 组织液 → 淋巴（毛细淋巴管盲端，单向进入）→ 回流血浆：单向水流。

理化性质三指标：渗透压（ 以上来自 与 ， 为等渗）、酸碱度（pH ，靠 等缓冲对）、温度（ 左右）。稳态的调节机制是神经—体液—免疫调节网络；稳态是细胞正常代谢（酶促反应）的必要条件。发烧、腹泻脱水、乳酸堆积、尿毒症，都是稳态失调的例子。

神经调节：毫秒级的「有线网络」

反射弧五环节：感受器 → 传入神经 → 神经中枢 → 传出神经 → 效应器。缺任何一环反射都不能完成；识别传入神经的标志是它带神经节。

兴奋在神经纤维上的传导靠电位变化：静息时外正内负（ 外流），受刺激时钠离子通道开放、 内流，变为外负内正（动作电位），与未兴奋部位形成局部电流而双向传导。

突触是神经元之间的「译电员」：

过程：动作电位到达突触小体 → 突触小泡释放神经递质（胞吐）→ 递质经突触间隙扩散 → 与突触后膜上的特异性受体结合 → 引发下一个神经元的兴奋或抑制。信号转换：电信号 → 化学信号 → 电信号。

由于递质只能由前膜释放、作用于后膜，突触间的传递是单向的。递质作用后会立即被分解或回收——药物成瘾、有机磷中毒（抑制乙酰胆碱的分解）都打在这条链条上。

大脑皮层是最高级中枢（语言、学习、记忆），脊髓等低级中枢受其分级调控（如大脑有意识地控制排尿）。

体液调节：激素的「邮政快递」

激素调节三特点：微量高效、通过体液运输、作用于靶器官靶细胞（受体特异性）。两个经典模型：

甲状腺激素的分级调节 + 反馈调节：下丘脑分泌促甲状腺激素释放激素（TRH）→ 垂体分泌促甲状腺激素（TSH）→ 甲状腺分泌甲状腺激素 → 代谢加快、产热增多；当甲状腺激素过多时反过来抑制下丘脑与垂体的分泌（负反馈，维稳的关键）。甲状腺激素还能促进发育——幼年缺乏患呆小症（侏儒症缺的是生长激素，别混淆）。

血糖调节：胰岛素（胰岛 B 细胞分泌）是唯一降血糖的激素（促进摄取、利用、储存）；胰高血糖素（胰岛 A 细胞）升血糖（促进肝糖原分解、非糖物质转化），两者拮抗；肾上腺素与之协同升糖。糖尿病「三多一少」（多食多饮多尿、体重减少）源于血糖去路受阻。

免疫调节：识别「非己」的安防系统

三道防线：皮肤黏膜（第一）、体液中的杀菌物质与吞噬细胞（第二）为非特异性免疫；第三道防线是特异性免疫，靠淋巴细胞「定制打击」：

  • 体液免疫：病原体被吞噬细胞摄取处理 → 呈递给 T 细胞 → T 细胞将抗原呈递给 B 细胞 → B 细胞增殖分化为浆细胞（分泌抗体，与抗原特异性结合）和记忆细胞；
  • 细胞免疫：T 细胞增殖分化为效应 T 细胞，与被病原体侵染的靶细胞密切接触使其裂解，释放出的抗原再由抗体消灭；
  • 二次免疫：同种抗原再次入侵时，记忆细胞迅速增殖分化，反应更快、更强（疫苗的原理）。

免疫功能的「翻车」模式：过强 → 过敏反应、自身免疫病；过弱 → 免疫缺陷病（HIV 攻击 T 细胞，导致 AIDS）。

植物激素：没有神经的协调

生长素（吲哚乙酸）由胚芽鞘尖端产生，极性运输（只能从形态学上端向下端运输）。核心性质是两重性：低浓度促进生长，高浓度抑制生长——

  • 顶端优势：顶芽产生的生长素向下运输积累在侧芽处，抑制侧芽发育；摘除顶芽（果树修剪）或喷施适宜浓度生长素类似物可解除；
  • 根向地、茎背地：重力使生长素横向分布，近地侧浓度高——根对生长素敏感（高浓度抑制 ⇒ 向地），茎不敏感（高浓度促进 ⇒ 背地）；
  • 应用：扦插枝条用一定浓度生长素类似物浸泡促生根；乙烯促进果实成熟；赤霉素促进茎的伸长与种子萌发；细胞分裂素促进细胞分裂；脱落酸抑制分裂、促进休眠与脱落——五类激素协同与拮抗，共同调节。

例：验证「生长素在胚芽鞘中的运输是极性运输（只能自形态学上端向下端）」。

设计对照：取两段胚芽鞘，一段正放（上端向上）、一段倒置（形态学下端朝上），分别在正放段的形态学上端（或倒置段的形态学下端）琼脂块上放含生长素的琼脂块，下端放置空白琼脂块接收；一段时间后测定空白琼脂块中是否含生长素。预期：只有「自上而下」方向能检测到生长素。变量控制：除放置方向外，琼脂块大小、时间、温度等完全相同。

记忆点：三张网的分工——神经管「快」（毫秒级、点对点），激素管「慢而广」（秒到分钟、经体液），免疫管「敌我」（识别与清除）。稳态的本质不是「不变」，而是在波动中被不断拉回的动态平衡，负反馈调节就是那只看不见的手。
