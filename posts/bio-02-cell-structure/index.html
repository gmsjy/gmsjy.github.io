细胞的结构与物质运输：一座有序运转的工厂

2026-09-16 生物分子与细胞高中

把细胞想成一座工厂：细胞膜是围墙与门卫，细胞器是各司其职的车间，细胞核是总部档案室，而物质运输就是厂内厂外的物流系统。本章的记忆任务很重，但「工厂类比」能帮你把零散的结构串成流水线。

细胞学说与原核、真核之别

细胞学说（施莱登、施旺）：一切动植物都由细胞发育而来，细胞是动植物结构的基本单位。它揭示了动植物之间的统一性。

最本质的分类依据是有无以核膜为界限的细胞核：

对比项 原核细胞 真核细胞
细胞核 无核膜，只有拟核（环状 DNA 集中区） 有核膜包被的细胞核
细胞器 只有核糖体（无膜细胞器） 有线粒体、内质网等一整套
细胞壁 主要成分肽聚糖（蓝细菌、多数细菌） 植物细胞壁主要成分纤维素和果胶
代表 蓝细菌（蓝藻）、细菌、放线菌 动物、植物、真菌

蓝细菌虽是原核，却含叶绿素和藻蓝素，能进行光合作用——「原核自养」的典型。判断窍门：带「菌」字的不一定都是原核（乳酸菌、大肠杆菌是原核，酵母菌、霉菌是真核）；带「藻」的未必是原核（蓝细菌原核，绿藻、衣藻真核）。

细胞膜：流动的门卫

制备细胞膜选哺乳动物成熟红细胞——没有细胞核和众多细胞器膜干扰，放进清水吸水涨破即可。成分：磷脂（双分子层构成基本骨架）与蛋白质（功能的主要承担者，种类数量与功能复杂程度相关），外侧还有糖蛋白（识别、信息交流）。

流动镶嵌模型的两个要点常被混为一谈：

  • 结构特点：具有一定的流动性（磷脂分子与大多数蛋白质都能运动）——胞吞胞吐、变形虫运动、细胞融合的原理；
  • 功能特性：选择透过性（水分子可自由通过、被选择的离子和小分子可以通过，大分子不能）。

细胞膜三大功能：将细胞与外界环境分隔开；控制物质进出细胞（相对性：病原体、毒素也能进来）；进行细胞间的信息交流（激素、胞间接触、胞间连丝）。

细胞器：分工明确的车间

细胞器 膜层数 功能要点
线粒体 双层 有氧呼吸的主要场所（动力车间），内膜向内折叠成嵴增大膜面积
叶绿体 双层 光合作用的场所（养料制造车间），类囊体堆叠成基粒
内质网 单层 蛋白质合成加工及脂质合成的「车间」，向内连核膜向外连细胞膜
高尔基体 单层 蛋白质加工、分类、包装的「发送站」；植物细胞中与细胞壁形成有关
核糖体 无膜 合成蛋白质（生产蛋白质的机器）
溶酶体 单层 内部含多种水解酶，「消化车间」，分解衰老细胞器、吞噬病菌
液泡 单层 含细胞液（糖类、无机盐、色素），调节植物细胞内环境，与花果颜色有关
中心体 无膜 动物细胞和低等植物细胞有，与细胞有丝分裂有关

分泌蛋白（如胰岛素、消化酶、抗体）的合成运输路线是年年必考的流水线：

核糖体（合成肽链）→ 内质网（加工成较成熟蛋白，出芽形成囊泡）→ 高尔基体（进一步加工包装，再出囊泡）→ 细胞膜（胞吐分泌）。全程需线粒体供能。研究该路径用同位素标记法（3H 标记亮氨酸），放射性依次出现在核糖体 → 内质网 → 高尔基体 → 细胞膜及分泌物的培养液中。

细胞核：遗传信息库、细胞代谢和遗传的控制中心。核膜双层、有核孔（大分子物质如 RNA、蛋白质的选择性通道，DNA 不能出）；核仁与某种 RNA 的合成及核糖体的形成有关；染色质（DNA + 蛋白质）是遗传信息的载体。

物质运输：被动、主动与大宗物流

方式 方向 载体 能量 典型实例
自由扩散 高浓度 → 低 不需要 不需要 、、、乙醇、甘油、苯
协助扩散 高浓度 → 低 需要（转运蛋白） 不需要 红细胞吸收葡萄糖
主动运输 低浓度 → 高（可逆浓度） 需要 需要 小肠吸收葡萄糖、氨基酸； 进入细胞
胞吞、胞吐 大分子、颗粒 不需要（依赖膜流动性） 需要 白细胞吞噬病菌；分泌蛋白排出

主动运输的意义：保证活细胞按照生命活动的需要，主动选择吸收营养物质、排出代谢废物——「想吸收的浓了也要吸，想排的稀了也要排」。

渗透作用与质壁分离

渗透作用发生的两个条件：具有半透膜；膜两侧溶液具有浓度差。水分子总净移动方向：向溶液浓度更高的一侧（低浓度一侧水「多」，往「稀」处跑的水分子反而少）。

植物细胞的渗透系统：原生质层（细胞膜 + 液泡膜 + 两膜之间的细胞质）相当于半透膜；细胞液与外界溶液构成浓度差。

实验要点：外界溶液浓度 细胞液浓度 ⇒ 细胞失水，发生质壁分离；再置于清水（或低浓度溶液）中 ⇒ 自动复原。用 蔗糖溶液（过浓细胞快速死亡不复原，过稀现象不明显）。不能用 、尿素等做「不复原」的对照组——它们能被细胞主动吸收，会自动复原。

该实验的三大用途：证明原生质层相当于半透膜；判断细胞的死活（死细胞不发生质壁分离）；粗略测定细胞液浓度范围（找「既不明显分离也不复原」的临界浓度）。

记忆点：本章一条主线——膜的选择透过性是活细胞功能的基石。被动运输「顺水推舟」，主动运输「逆流而上」要耗 ATP；质壁分离就是一张活的渗透压试卷，细胞用失水还是复原「作答」。
